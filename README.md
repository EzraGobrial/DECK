# DECK — One More Run

**DECK** is a 3D skateboard speedrunning game where you are the board. Race through ramps, wall rides, drops, towers, boosts, and risky shortcuts. Master tilt, momentum, and your own ghost to beat your best time.

## Play

Open `index.html` in a modern browser, or enable GitHub Pages for this repository and play it from the published site.

## Controls

- **Keyboard:** WASD or arrow keys to drive/steer, Space to double jump, Q/E to roll, I/K to pitch, R to reset, and Esc/P to pause.
- **Controller:** R2/RT forward, L2/LT brake/reverse, left stick steer, A/Cross double jump, L1/R1 tilt, R3 reset, and Start pause.

## Included

- 28 time-trial courses with stacked floors, towers, routes, transfers, ramps, bowls, boosts, jump pads, and bumpers.
- Local personal-best saves and your best-run ghost replay.
- Controller menus, Locker, cosmetic board/wheel shop, and generated menu music.

All assets are local; no install or server is required.
