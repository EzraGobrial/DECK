# DECK — One More Run

**DECK** is a 3D skateboard speedrunning game where you are the board. Carve through bowls, ramps, drops, towers and crossing decks. Try different routes, learn their shapes, and race your own ghost to find your line.

## Play

[Play DECK](https://ezragobrial.github.io/DECK/deck-prototype.html), or open `index.html` locally in a modern desktop browser.

## Controls

- **Keyboard:** WASD or arrow keys to drive/steer, Space to double jump, Q/E to roll, I/K to pitch, R to reset, and Esc/P to pause.
- **Controller:** R2/RT forward, L2/LT brake/reverse, left stick steer, A/Cross double jump, L1/R1 tilt, R3 reset, and Start pause. On the course-selection screen, L1/R1 switch packs.

## Included

- 31 time-trial courses across six packs. Flow State now has much longer spillway, elevated transfer, and rooftop courses, with substantial return sections and connected alternatives.
- Rebuilt Wide Awake, Skyline and Over Under with linked bowls, terrace descents and a two-level crossing. Route labels do not tell you which line is fastest.
- New Air Mail, Cloud Nine, Undertow and Vertigo layouts add high drop-ins, receiving bowls and stacked terraces.
- Downhill momentum can exceed the flat-ground driving limit, and fast crests let the board lift naturally. Rolling wheel audio follows speed and ground contact.
- Svens Board: 7,777 earned coins, animated gold-and-black stripes and a Happy B-Day grip graphic.
- Every finished run earns 50 coins, with additional one-time medal progress bonuses. No real-money purchases.
- Local personal-best saves and your best-run ghost replay.
- Controller menus, Locker, cosmetic board/wheel shop, and generated menu music.

All assets are local; no install or server is required.

Worldwide leaderboards and other players' ghosts are not enabled. Firebase setup is deferred; current personal bests and replays stay in this browser.
