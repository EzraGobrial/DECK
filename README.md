# DECK — One More Run

**DECK** is a 3D skateboard speedrunning game where you are the board. Carve through bowls, ramps, drops, towers and crossing decks. Try different routes, learn their shapes, and race your own ghost to find your line.

## Play

Open `index.html` in a modern browser, or enable GitHub Pages for this repository and play it from the published site.

## Controls

- **Keyboard:** WASD or arrow keys to drive/steer, Space to double jump, Q/E to roll, I/K to pitch, R to reset, and Esc/P to pause.
- **Controller:** R2/RT forward, L2/LT brake/reverse, left stick steer, A/Cross double jump, L1/R1 tilt, R3 reset, and Start pause.

## Included

- 31 time-trial courses across six packs, including the new Flow State spillway, elevated transfer, and rooftop gap routes.
- Rebuilt Wide Awake, Skyline and Over Under with linked bowls, terrace descents and a two-level crossing. Route labels do not tell you which line is fastest.
- Svens Board: 7,777 earned coins, animated gold-and-black stripes and a Happy B-Day grip graphic.
- Every finished run earns 50 coins, with additional one-time medal progress bonuses. No real-money purchases.
- Local personal-best saves and your best-run ghost replay.
- Controller menus, Locker, cosmetic board/wheel shop, and generated menu music.

All assets are local; no install or server is required.
